### 操作流程

1. **添加文件** — 点「添加文件」、把文件拖进列表，或点「添加文件夹」批量导入
2. **选输出目录** — 留空则默认在源文件旁边建 `converted` 文件夹
3. **选采样率** — 一般保持「自动」；F1A 音调不对时再改（见下）
4. **点「开始转换」**

### 选项说明

| 选项 | 默认 | 说明 |
|---|---|---|
| **输出目录** | 源文件夹下 `converted` | 转换结果的存放位置 |
| **采样率** | 自动 | 覆盖容器里读到的采样率 |
| **覆盖已存在的文件** | 勾选 | 取消勾选则遇到同名文件会跳过并报错 |
| **保留编码器预热样本** | 不勾选 | 仅对 `.a`/`.b`/`.e` 有效；勾选可保留编码阶段丢弃的样本 |

### 快捷键

| 按键 | 功能 |
|---|---|
| `Ctrl+O` | 添加文件 |
| `F5` | 开始转换 |
| `Delete` | 移除选中项 |

### 高分屏

界面通过 `ctypes` 调用 `SetProcessDpiAwarenessContext`
（per-monitor v2）声明 DPI 感知，并按显示器 DPI 计算缩放系数。
在 125% / 150% / 200% 缩放下文字都保持锐利，
多显示器之间拖动窗口也会按当前显示器重新适配。

## 命令行

```bash
python wav_tool/jie2wav.py 输入 [输入 ...] [选项]
```

### 参数

| 参数 | 说明 |
|---|---|
| `INPUT...` | 输入文件、通配符或目录 |
| `-o, --outdir DIR` | 输出目录，默认当前目录 |
| `-r, --rate HZ` | 覆盖采样率 |
| `--raw-delay` | 保留编解码器预热样本（仅 `.a`/`.b`/`.e`）|
| `--info` | 只打印格式信息，不转换 |
| `-v, --verbose` | 失败时打印详细堆栈 |
| `--version` | 版本号 |

### 示例

```bash
# 单个文件，输出到当前目录
python wav_tool/jie2wav.py 音乐.f1a

# 批量，输出到 out/
python wav_tool/jie2wav.py *.f1a *.a *.ump3 -o out

# 整个文件夹
python wav_tool/jie2wav.py 我的音频库 -o 转换结果

# 看文件内部结构
python wav_tool/jie2wav.py --info 音乐.f1a

# F1A 音调不对，试 16 kHz
python wav_tool/jie2wav.py 音乐.f1a -r 16000
```

## 输出规则

- 输出格式固定为 **16-bit PCM 单声道 WAV**
- 文件名 = 输入文件名去掉原扩展名 + `.wav`

**同名去重**：如果同一个目录里同时有 `音乐.a`、`音乐.b`、`音乐.e`，
直接转换会互相覆盖，所以工具会自动加扩展名区分：

```
音乐.a  →  音乐_a.wav
音乐.b  →  音乐_b.wav
音乐.e  →  音乐_e.wav
```

## 采样率怎么选

**`.a` `.b`** — 固定 8000 Hz，容器里没存别的。

**`.e`** — 从容器第 4 字节的采样率码读取：

| 码 | 采样率 |
|---|---|
| `0x00` | 8000 |
| `0x01` | 16000 |
| `0x02` | 32000 |
| `0x03` | 12000 |
| `0x04` | 24000 |
| `0x77` | 哨兵值（编码器对其它采样率写这个），工具按 16000 处理 |

**`.ump3`** — 从 MP3 帧头读，准确。

**`.f1a`** — ⚠️ **需要人工判断**。

F1A 文件里没有可靠的采样率字段，官方解码器又固定写 16000。
工具默认按 **8000 Hz** 处理，这是实测校验过的值：

| 判据 | 结果 |
|---|---|
| 听感 | 8000 Hz 下音调正常 |
| 节奏自相关 | 130.4 BPM，正好落在 Funk 典型区间 125–135 |
| 隐含码率 | 7,943 bit/s，符合 8 kHz 低码率音乐 |

**怎么判断对不对**：听速度。如果听起来像慢放（声音拖沓、低音发闷），
说明采样率设高了；像快进（声音尖、语速快）则设低了。

可选的档位：`8000` `11025` `12000` `16000` `22050` `24000` `32000` `44100`

## 自检

```bash
# 后端：验证 F1A 容器解析、A/B/E 字节级重编码、UMP3 结构、端到端转换
python wav_tool/selftest.py

# 界面：构建完整窗口，跑一次真实转换，验证线程与队列
python wav_tool/gui_selftest.py
```

两套测试都**不需要人工点击**，且在没有官方样本数据时会**自动生成测试文件**，
所以在任何机器上都能运行。

```
有完整样本: 36 项通过 / 0 失败
无样本    : 15 项通过 / 0 失败
GUI       : PASSED
```
