# 杰理音频工具与格式白皮书

杰理（JieLi）AD14N / SH50 系列芯片音频格式的完整逆向分析与转换工具。
原文工具已经很难找到了，这里一并附上。

### 2️⃣ 提取出的命令行工具（脚本 / 高级用户）

**`jieLi-cli-tools.zip`** · 22.4 MB（解压后 55.5 MB）

官方 GUI 内部其实打包了 **18 个独立命令行工具**，这个包里是提取好的版本：

| 类别 | 工具 |
|---|---|
| **编解码** | `testf1a_dec.exe` `test_f1aencode.exe` `f1c_test_f1aencode.exe` `add_f1a_head.exe` |
| **ADPCM** | `wavtoa.exe` `e_wavtoa.exe` `raw2rawbig.exe` |
| **媒体** | `ffmpeg.exe` `ump3_ffmpeg.exe` `WMAEncode.exe` `jlwma.exe` `cutmp3_energy.exe` |
| **BR20 开发** | `br20_mp3convert.exe` `br20_mp3dec.exe` |
| **运行库** | `msvcr100.dll` `msvcr100d.dll` `vcruntime140.dll` |

**提取方式**：官方 exe 是 UPX 加壳的，尾部附着一个 zlib 压缩归档
（偏移 `0x4F2007`，解压后 58,151,936 字节，18 个条目）。
完整过程见 [docs/格式白皮书.md](https://github.com/Jihao2048/jieli-audio-whitepaper/blob/main/docs/%E6%A0%BC%E5%BC%8F%E7%99%BD%E7%9A%AE%E4%B9%A6.md)。

**常用命令**：

```bash
# F1A 解码（需要 msvcr100.dll 同目录）
testf1a_dec.exe  in.f1a  out.wav

# F1A 编码（只吃 ASF/WMA 输入）
test_f1aencode.exe  in.wma  out.f1a  0  0  out.raw

# WAV → .a（只接受恰好 8000 帧的 16-bit 单声道）
wavtoa.exe  in.wav  out.a

# WAV → .e（可选采样率 8000/12000/16000/24000/32000）
e_wavtoa.exe  in.wav  out.e  16000
```

> ⚠️ **这些工具必须用绝对路径调用**，否则会以 `0xC0000417` 崩溃。
>
> ⚠️ 大部分工具缺参数时会直接崩溃而不是打印用法。

## 🔬 关于本仓库

这两个包里的工具，**全部已经被完整逆向并记录成白皮书**：

| 格式 | 真相 | 验证方式 |
|---|---|---|
| `.ump3` | **就是普通 MP3** | 同源同参数存成两个扩展名，SHA-256 完全相同 |
| `.a` `.b` `.e` | **标准 IMA ADPCM 4bit** | 字节级重编码往返，一致度 **1.000000** |
| `.f1a` `.f1b` `.f1c` | 真·私有频谱编码 | 容器结构完全还原，帧内参数未解 |

**白皮书包含**：UPX 脱壳过程、18 个工具的提取方法、每个字节的来历、
以及**失败的假设和为什么失败**。

📖 [docs/格式白皮书.md](https://github.com/Jihao2048/jieli-audio-whitepaper/blob/main/docs/%E6%A0%BC%E5%BC%8F%E7%99%BD%E7%9A%AE%E4%B9%A6.md)

## 🚀 只是想把文件转成 WAV？

不用下载这些，直接用仓库里的工具就行：

```bash
git clone https://github.com/Jihao2048/jieli-audio-whitepaper
cd jieli-audio-whitepaper
python wav_tool/jie2wav.py 你的文件.f1a
```

或者双击 `启动转换工具.bat` 用图形界面。

支持 `.f1a` `.f1b` `.f1c` `.a` `.b` `.e` `.ump3` 七种格式。
